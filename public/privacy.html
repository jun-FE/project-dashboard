개인정보처리방침

시행일: 2026년 9월 25일

메모봇은 운영자 한 사람이 자기 메모와 일정을 관리하려고 쓰는 개인용 도구입니다. 운영자 외의 사용자를 받지 않습니다.

1. 다루는 정보

  • 운영자가 텔레그램 봇에 보낸 메모, 사진, 파일
  • 운영자의 구글 캘린더 일정 (제목, 시간, 장소, 설명)

2. 쓰는 목적

  • 메모 저장, 검색, 분류
  • 메모에서 나온 일정을 운영자의 구글 캘린더에 등록하고 옮기기
  • 일정과 할 일을 시작 전에 텔레그램으로 알리기

3. 구글 사용자 데이터

메모봇은 구글 캘린더 권한(calendar.events)으로 운영자 본인의 기본 캘린더 일정을 읽고, 메모에서 나온 일정을 만들거나 옮깁니다. 구글 데이터는 위 목적에만 쓰고, 판매하거나 광고에 쓰거나 제3자에게 넘기지 않습니다. 메모봇의 구글 API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 보관 위치

  • 메모: 운영자의 Supabase 데이터베이스 (운영자만 접근)
  • 첨부 파일과 구글 인증 토큰: 운영자의 개인 컴퓨터
  • 캘린더 일정: 운영자의 구글 캘린더 (메모봇은 알림에 필요한 만큼만 읽고 따로 쌓아두지 않습니다)

5. 삭제

운영자는 언제든 메모를 지울 수 있고, 구글 계정 권한 페이지에서 메모봇의 캘린더 접근을 끊을 수 있습니다.
